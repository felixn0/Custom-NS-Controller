This is a custom built NS Pro Controller, built entirely from off-the shelf parts, using existing firmware tweaked for the hardware. This requires hand-wiring the circuitry, 3D printing an adequate shell, and soldering/connecting parts properly together. 

STEP 1:
- Purchase all parts listed in BOM
- 3D print the shell parts

STEP 2:
- Flash the firmware to the ESP32 using a Micro USB data cable (further instructions coming)

STEP 3: 
- Wire all components together to the ESP32 (Wiring diagram coming)

STEP 4: 
- Screw all components into the shell (Instructions coming)
- Screw controller fully together

STEP 5: 
- Turn on and test the controller!
